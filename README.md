# Я оставил тебе знаки

Личный квест: сайт ведёт к воспоминаниям и реальным местам. Сейчас готова только прелюдия: секретное слово открывает сообщение «история готовится». Реальные загадки и выдача приза ещё не добавлены.

## Локальный просмотр

Нужен Node.js. В папке проекта выполните `npm start`, затем откройте http://127.0.0.1:4173. Установка пакетов не нужна. Не открывайте HTML двойным щелчком: загрузка зашифрованной истории требует HTTP.

## Свой код и сообщение

1. Измените `private/story.json`. Эта папка исключена из Git. На новом компьютере создайте её и скопируйте туда `story.example.json` под именем `story.json`.
2. Выполните `npm run seal` и введите новое секретное слово. Ввод в терминале виден, но слово не записывается в файлы.
3. Закоммитьте обновлённый `dist/sealed.json`. Регистр, ё/е и лишние пробелы не влияют на ответ.

Публичный экран: `dist/index.html`. Оформление: `dist/style.css`. Логика открытия: `dist/app.js`. Подсказка меняется в HTML.

## GitHub Pages — когда будете готовы

Репозиторий локально подготовлен, публикация не выполнена. Создайте GitHub-репозиторий, добавьте remote, сделайте первый коммит и отправьте ветку main. В Settings → Pages выберите GitHub Actions. Готовый workflow публикует только `dist/` при push в main. Относительные пути подходят и для адреса вида username.github.io/repository/.

## Что скрыто

Содержимое после входа зашифровано AES-GCM, ключ получается из ответа через PBKDF2. Открытого ответа и текста истории в публикуемой папке нет. Это игровой барьер, а не полноценная авторизация: короткое слово или цифры можно перебрать офлайн. Сам адрес сайта и стартовый экран публичны. Не размещайте здесь действующий сертификат, его номер или личные фото без отдельного решения о защите. `noindex` — просьба поисковикам, не контроль доступа.

## Следующие главы

1. Отдельно переданная подсказка → входное слово.
2. Проверенная деталь в её лифте → первая координата.
3. Записка в общем офисе → воспоминание и следующая загадка.
4. Финальная встреча → подарок.

Не публикуйте ответы и будущие секреты в HTML или истории Git. Перед запуском замените демонстрационный код.
