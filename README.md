# Между нами

Личный квест со звёздным небом, голосовой сценой, загадками и поиском подсказки в офисе. Текущая версия заканчивается ожиданием встречи во вторник; реальный подарок и место встречи пока не добавлены.

## Запуск

Нужен Node.js. Выполните `npm start`, откройте http://127.0.0.1:4173. Зависимости устанавливать не нужно. Открывать index.html двойным щелчком не следует: история загружается через HTTP.

## Файлы

- `dist/index.html` — стартовый экран и контейнер квеста.
- `dist/style.css` — оформление, адаптив и анимации.
- `dist/app.js` — сцены, ответы, аудио и сохранение прогресса.
- `dist/sky.js` — созвездия.
- `dist/sealed.json` и `dist/voice.bin` — зашифрованные материалы.
- `private/story.json` — локальные тексты и ответы, исключены из Git.
- `private/joke.mp3` — исходная запись, исключена из Git.

Чтобы изменить закрытые материалы, отредактируйте private/story.json и выполните `npm run seal`. Скрипт запросит входной код и заново зашифрует историю и запись. Оба зашифрованных файла должны публиковаться вместе. На другом компьютере восстановите private/ из своей локальной копии; Git не содержит исходной записи или закрытой конфигурации. story.example.json показывает только структуру.

Прогресс сохраняется в localStorage этого браузера. После закрытия вкладки нужно снова ввести код; история продолжится с сохранённой сцены. Синхронизации между устройствами нет. Для отдельного пробного прохождения используйте приватное окно. На телефоне звук может потребовать дополнительного нажатия кнопки воспроизведения. При включённом системном уменьшении движения анимации отключаются.

## Публикация

Push в main запускает GitHub Actions и публикует только dist/. В Settings → Pages должен быть выбран GitHub Actions. Локальная папка private/ не публикуется. Печатную подсказку также не кладите в dist/.

## Границы защиты

Вход — игровой барьер, а не авторизация. История и голосовая запись зашифрованы AES-GCM с PBKDF2, но короткий код можно подобрать. Клиентская логика и прогресс доступны для изменения через инструменты браузера. Не размещайте действующий сертификат или его реквизиты в репозитории. Передайте его лично в финале.
